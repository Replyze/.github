# Contributing to Replyze repositories

Thank you for helping. Fixes to the SDKs, the WordPress plugin, the examples and the docs are welcome.

## Before you start

- **Bugs:** open an issue first if the fix is not obvious, so we can agree on the approach.
- **Features of the Replyze product** (the dashboard, the AI agent, the inbox) are not built here. Send those ideas to support@replyze.chat.
- **Security problems:** do not open an issue. See [SECURITY.md](SECURITY.md).

## Pull requests

1. Fork the repository and create a branch from `main`.
2. Keep the change small and focused on one thing.
3. Follow the repository's README: its "Development" section says how to install, test and build.
4. Add or update tests when you change behaviour. CI must pass.
5. Describe what you changed, why, and how you tested it.

Code samples and docs must match what the widget and the API really do today. Please don't document an option, endpoint or event that does not exist yet.
