# Security policy

## Reporting a vulnerability

Please report security problems privately, never in a public issue or pull request.

- **On GitHub:** open the repository's **Security** tab and click **Report a vulnerability**.
- **By email:** support@replyze.chat with "Security" in the subject.

This covers the code in every repository of this organization and the Replyze service itself: `replyze.chat`, `client.replyze.chat` (dashboard and API) and `cdn.replyze.chat` (the chat widget).

Please include:

- what is affected (a repository and version, or a URL),
- steps to reproduce, or a proof of concept,
- the impact you expect.

Test only against your own Replyze workspace and your own data. Do not access other customers' data, run denial-of-service or volume tests, or send spam through the product.

We read every report, keep you updated while we fix it, and credit you when it is fixed if you want to be named.

## Supported versions

Fixes go into the latest release of each package. Please update to it before you report.
