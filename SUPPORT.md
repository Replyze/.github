# Getting help

| You need help with | Where to go |
|---|---|
| Your Replyze account, billing, the dashboard or the AI agent's answers | Email **support@replyze.chat**, or open the chat on [replyze.chat](https://replyze.chat/?utm_source=github&utm_medium=support) and ask a person |
| A bug in one of these repositories (an SDK, the WordPress plugin, an example) | Open an issue in that repository, with the version and steps to reproduce |
| An integration or framework that is missing | Open an issue with the "Integration request" form in the closest repository |
| How the widget, REST API, webhooks or MCP server work | The developer docs: [github.com/Replyze/replyze](https://github.com/Replyze/replyze) |
| A security problem | Do not open a public issue. See [SECURITY.md](SECURITY.md) |

When you report a problem, never paste API keys (`rpz_live_...`), your identity secret or customer data. A widget token (`wgt_...`) is public by design, so it is fine to include.
